# SportTime PWA

Личный кабинет клиента тренажёрного зала SportTime — Progressive Web App.

## Файлы

- `index.html` — основное приложение
- `manifest.json` — PWA-манифест
- `service-worker.js` — service worker для установки
- `icon-192.png`, `icon-512.png` — иконки приложения
- `apple-touch-icon.png` — иконка для iOS
- `.nojekyll` — отключает Jekyll на GitHub Pages

## Деплой на GitHub Pages

1. Создай репозиторий на GitHub (например, `sporttime-lk`)
2. Загрузи все файлы из этой папки
3. Settings → Pages → Source: `main` branch, `/ (root)`
4. Приложение будет доступно по адресу:
   `https://ТВОЙ_ЛОГИН.github.io/sporttime-lk/`

## Установка на телефон

### Android (Chrome):
1. Открой URL в Chrome
2. Меню (три точки) → «Установить приложение» / «Добавить на главный экран»
3. Подтверди установку

### iOS (Safari):
1. Открой URL в Safari
2. Кнопка «Поделиться» → «На экран "Домой"»
3. Подтверди добавление

## QR-код

Сгенерируй QR-код на URL:
`https://ТВОЙ_ЛОГИН.github.io/sporttime-lk/`
